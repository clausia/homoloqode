# Reading List

This file collects the main references for the **homoloQode** project.

The goal is not to cover the full literature on topological quantum error correction, but to maintain a focused and evolving list of papers that support the first stages of the project.

## Core references

### 1. Daniel Gottesman — *Stabilizer Codes and Quantum Error Correction*

Link: https://arxiv.org/abs/quant-ph/9705052

Purpose: Basic reference for stabilizer codes, Pauli errors, syndrome measurements, logical operators, and code distance.

### 2. A. R. Calderbank and Peter Shor — *Good Quantum Error-Correcting Codes Exist*

Link: https://arxiv.org/abs/quant-ph/9512032

Purpose: Foundational reference for CSS codes and the construction of quantum codes from classical binary codes.

### 3. Andrew Steane — *Multiple-Particle Interference and Quantum Error Correction*

Link: https://arxiv.org/abs/quant-ph/9601029

Purpose: Foundational reference for quantum error correction and CSS-type code constructions.

### 4. Eric Dennis, Alexei Kitaev, Andrew Landahl, and John Preskill — *Topological Quantum Memory*

Link: https://arxiv.org/abs/quant-ph/0110143

Purpose: Core reference for toric/surface codes, topological memories, logical operators as nontrivial cycles, and decoding intuition.

### 5. Héctor Bombin and Miguel A. Martin-Delgado — *Homological Error Correction: Classical and Quantum Codes*

Link: https://arxiv.org/abs/quant-ph/0605094

Purpose: Main reference for the homological formulation of classical and quantum error correction.

## Secondary references

### 6. Sergey Bravyi and Alexei Kitaev — *Quantum Codes on a Lattice with Boundary*

Link: https://arxiv.org/abs/quant-ph/9811052

Purpose: Useful once the project moves from periodic toric-code examples to planar surface codes with boundaries.

### 7. Alexei Kitaev — *Fault-tolerant quantum computation by anyons*

Link: https://arxiv.org/abs/quant-ph/9707021

Purpose: Conceptual and historical source for the toric code, anyonic excitations, and topological quantum computation.

### 8. Sergey Bravyi and Robert König — *Classification of Topologically Protected Gates for Local Stabilizer Codes*

Link: https://arxiv.org/abs/1206.1609

Purpose: Establishes the dimensional bound on geometrically local constant-depth logical gates in topological stabilizer codes. It provides the main limitation against which proposed fault-tolerant logical-gate constructions should be compared.

### 9. Nikolas P. Breuckmann, Margarita Davydova, Jens N. Eberhardt, and Nathanan Tantivasadakarn — *Cups and Gates I: Cohomology Invariants and Logical Quantum Operations*

Link: https://arxiv.org/abs/2410.16250

Purpose: Develops cohomology invariants and cup products as a systematic construction of diagonal logical gates for CSS codes, including constant-depth copy-cup gates for selected qLDPC code families.

## Notes

PDF files are not stored in this repository. Stable arXiv links are used instead.

If local PDF copies are needed for reading, they should be kept outside version control.
